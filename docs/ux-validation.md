# UX 驗收

本清單用於 Terminal 閱讀介面。自動化測試使用 mock 來源、合成 DOM 與暫存 profile；不能代替真實 Threads 登入與網站版面驗證。

## 自動化回歸

- 清除登入資料：先確認、預設取消；取消不清除 profile、不關閉瀏覽器，確認才執行。
- 狀態導引：未登入、等待驗證、讀取完成、瀏覽器關閉與錯誤，各自提供可執行的下一步。
- 忙碌操作：避免重複讀取，顯示正在執行的工作；結束後恢復可用操作。
- 閱讀：文章列表直接顯示完整內文，留言列表保留摘要；遠端文字不得解讀為 Rich markup。
- 原文：只有使用者明確操作才開啟連結。
- 快捷鍵：文章／留言詳情不顯示無效的首頁操作；返回後恢復首頁快捷鍵。
- 位置：追加與移除較舊項目時，盡可能保留仍存在的文章、焦點及畫面位置。
- 尺寸：110×35、80×24、60×20 檢查工具列、內容、狀態、確認視窗與鍵盤操作。

執行完整驗證：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m mythread --self-test
git diff --check
```

## 人工任務

請由未接觸專案的人執行；觀察第一次選擇的操作、是否需要提示，以及能否自行恢復。

1. 首次啟動，依畫面指示開啟登入視窗，完成手動驗證後開始閱讀。
2. 找到一篇長文章，開啟全文、查看原文，再返回列表。
3. 開啟留言，辨認所屬原文，讀取更多後返回原先文章與首頁位置。
4. 誤關網站瀏覽器，依提示恢復閱讀；需要驗證時能回到登入流程。
5. 在讀取中重複按操作鍵，確認回饋清楚；要求離開後能正常清理專用瀏覽器。
6. 開啟清除登入確認後取消，確認既有登入仍可使用；僅在測試帳號／測試 profile 上確認清除行為。
7. 將 Terminal 縮至 60×20，以滑鼠與鍵盤檢查首頁、文章、留言及確認視窗的入口。

記錄版本、作業系統、Terminal、尺寸、可見／背景模式及完成情形。回報使用虛構內容與匿名診斷，不附登入資料、私人文章或完整 DOM。可攜版仍需依 [Windows 驗收](portable.md) 在乾淨機器另外驗證。
